### First Town

```
     [D]  [V^] [pv]   passage to second-town
      |  /    /
      | /    /
[E]  [Gv] [T^]
   \  |  /
    \ | /
[t]--[ ]--[Av]        down to First Dungeon, Level 1
      |
      |
[a]--[ ]--[W]         sw to The Mountains
      |
      |
     [M]
```

Key:

- `A` — Arena
- `a` — Armor Shop
- `D` — Docks
- `E` — Equipment Shop
- `G` — Guild Hall
- `M` — Magic Shop
- `p` — Private Room
- `T` — Tavern
- `t` — Temple
- `V` — Town Vaults
- `W` — Weapon Shop

`[ ]` — a room with no shop or service (plaza, path, corridor).
`^` / `v` — an exit up / down.
